Game Overview

A catching game where the player moves a paddle to catch falling objects and earn points. The difficulty increases as the level goes up.

Rules / Game Flow
 • Move the player left and right using mouse/drag.
 • Objects fall from the top — catch them to stay in the game.
 • If one object reaches the ground without being caught → Game Over.
 • You can restart using the Restart button.

Scoring System
 • Each caught object = +1 point.
 • Every 5 points → level increases (up to level 10).
 • As levels increase, the game becomes harder.

Problem Types by Level (Difficulty Changes)
 • Low levels: slower, fewer falling objects.
 • Mid levels: more objects, faster speed.
 • High levels: many fast objects — harder to catch.

Special Features
 • Drag control for easy movement.
 • Restart option to replay instantly.
 • Game Over alert showing final score and level.
 • Player paddle slightly grows as levels increase.
